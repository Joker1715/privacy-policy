Privacy Policy

JokerDuty and related Discord bot services

Last updated: October 11, 2026
This policy currently documents JokerDuty based on its application code. Other bots are not automatically covered until their data processing is reviewed and added here.

1. About JokerDuty

JokerDuty supports gaming-community administration, including staff duty tracking, role assignment, moderation, warnings, activity statistics, and administrative notifications. It operates within Discord communities.

2. Information processed

Depending on the feature used, JokerDuty processes Discord user and server IDs, display names, server membership and roles, duty status and timestamps, duty session durations, weekly/monthly/total activity totals, warning counts, administrative actions, and commands issued to the bot. Some command content and notification previews are included in audit messages posted to designated Discord channels.

3. Why this information is used

Information is used to operate bot commands, calculate duty statistics, verify permissions, manage membership and roles, provide moderation functionality, send relevant direct messages, and produce operational logs. The operator states that these features are intended for gaming-community administration, not advertising or sale of user data.

4. Storage and access

Duty information is written to a local JSON file (duty_data.json) on the bot's hosting environment. The bot also posts audit information to designated Discord channels. Membership event information may be written as local JSON bridge files for interaction with another bot. Access to Discord audit channels depends on server channel permissions; hosting access is controlled by the operator and hosting provider.

5. Discord permissions

JokerDuty uses the Server Members Intent for membership events and role-related features, and the Message Content Intent to process text commands prefixed with !. The reviewed code does not enable the Presence Intent.

6. Retention and deletion

The bot has administrative functions to remove some user records and reset duty totals. The reviewed code does not establish a universal automatic deletion period for all stored data or Discord audit messages. No fixed automatic deletion period is implemented for all records. For questions about stored information or requests for deletion, contact the operator using the address below. Requests will be reviewed, including whether data remains in audit channels or bridge files; deletion may require manual administrative action.

7. Data sharing

JokerDuty uses Discord to deliver messages and a hosting environment to run the application. Relevant administrative information may be visible to authorized community staff. The operator states that data is not sold or used for advertising. This statement does not exclude the technical processing necessary to run the service.

8. Security

The bot checks Discord roles before allowing certain administrative commands. Protection of hosting files, bot credentials, backups, and administrative Discord channels remains the operator's responsibility.

9. Your rights and contact

Users may request information about their records or ask for deletion where applicable. Operator contact: joker.artur22@gmail.com.

10. Changes and other bots

This policy will be updated when JokerDuty's processing changes. FKJump, HoriBot, and any other applications require a separate review of their actual behavior before being listed as covered services.

This page describes the JokerDuty bot features reviewed as of the date above. Contact the operator with privacy questions or requests.
